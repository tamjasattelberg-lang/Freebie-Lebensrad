# Was mein Körper mir sagen will

**Mein Veränderungsweg · Tanja Sattelberg**  
veraenderungsweg.de

---

## Über diesen Kurs

Ein Selbstlernkurs in 7 Modulen zur bewussten Wahrnehmung von Körpersignalen und Gefühlen.  
Für Frauen, die lernen möchten, ihrem Körper wieder zuzuhören — sanft, alltagsnah, in eigenem Tempo.

**Theoretische Grundlagen:**
- Polyvagaltheorie (Porges / Dana)
- Psychosomatischer Ansatz (Maurer)
- Systemisches Coaching

## Technische Details

- Einzelne HTML-Datei — keine Installation nötig
- Läuft vollständig lokal im Browser
- Alle Daten bleiben im localStorage des Geräts
- Mobile First — optimiert für Smartphone-Nutzung
- Modul-Unlocking: sequenziell, ein Schritt nach dem anderen
- Spracheingabe für Reflexionsfelder (Web Speech API)
